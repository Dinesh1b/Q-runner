# Audit Module — Skills Checklist

This checklist lists what each role needs to be able to do in the Stockount Audit
module. Use it to plan training, sign people off before their first live audit, or
check yourself. For how to do each task, see the
[Audit Module — User Guide](./audit-user-guide.md).

Tick a skill only after the person has done it themselves — in the **Demo Audit** or a
test item group is fine.

---

## Everyone

- [ ] Open **Audit** from the application switcher and select the correct **branch**.
- [ ] Find an audit in **Ongoing Audits**, **Audit History** and **Archived Audits**.
- [ ] Open an audit and move between **Audit Summary**, **Settings** and **Stock Audit**.
- [ ] Use the **Steps to complete the audit** panel (**?** button) to see where an audit stands.
- [ ] Explain the difference between an audit owner, a contributor and an auditor.
- [ ] Explain what *expected quantity*, *audited quantity* and *variance* mean.

---

## Auditor

**Getting ready**

- [ ] Find the audits you are assigned to.
- [ ] Explain what **blind count** means and why you may not see the expected quantity.
- [ ] Know which locations or categories you are assigned, if the audit divides the work.

**Counting**

- [ ] Select the audit location before counting.
- [ ] Find an item by code, name or EAN.
- [ ] Scan a barcode with a handheld scanner.
- [ ] Scan a barcode with the device camera, and use **Continuous Count**.
- [ ] Enter **Audited Qty** and save the count.
- [ ] Record **Damaged Qty** separately, when it is allowed.
- [ ] Count a batch-, expiry- or serial-tracked item with its details.
- [ ] Explain that counting the same item again **adds** to the earlier count, and enter only the extra quantity.
- [ ] Respond correctly when Stockount asks whether to update an item's location.
- [ ] Take photos when photo validation asks for them.

**Finishing**

- [ ] Add declaration notes for anything unusual.
- [ ] Select **Finish Audit** once everything assigned is counted.
- [ ] Count a line again when it is assigned to you as a **Recount**.

**Location (Warehouse) audits** — only for teams that count by pallet and case

- [ ] Scan a pallet, then the cases on it, then items inside a case where needed.
- [ ] Scan a case where it actually is, even if the record says another pallet.
- [ ] Explain what *pallet roll-down* and *sealed case credit* do, and why credited counts are *assumed*, not verified.

---

## Audit Owner

**Planning**

- [ ] Choose the right audit type: Complete Count, Cycle Count, Partial Audit, Investigation Audit or Quick Audit.
- [ ] Create an audit plan with item group, owners, contributors, stock source, frequency, dates and auto-completion days.
- [ ] Choose between **Real Time** and **Stock Report** as the stock source and explain why.
- [ ] Assign auditors and divide the work with a mapping type (Random, By Category, By Location).
- [ ] Create a Partial Audit from **Suggested Audits** and explain what the suggestion lists are for.
- [ ] Create an Investigation Audit from items flagged earlier.
- [ ] Create and run a Quick Audit.
- [ ] Rerun a plan and mark a cycle as complete.

**Settings and the stock sheet**

- [ ] Turn on and explain: **Enforce assigned location**, **Restrict auditors counting same item**, **Allow damaged quantity**, **Blind count**, **Geo-tagging**, **Photo validation**.
- [ ] Set up a **Cross check** (Random Recheck, Discrepancy Recheck or Photo validation) and pick the cross-check auditor.
- [ ] Import a stock sheet and check its line count and total quantity before counting starts.
- [ ] Recognise *Waiting for stock from …* on a connected item group, and know not to start counting until the sheet arrives.

**Monitoring and review**

- [ ] Read the **Audit Summary**: audited vs. total lines and quantities, and matched, positive and negative lines.
- [ ] Spot an auditor or area that is falling behind and act on it.
- [ ] Export the audit reports.

**Resolution**

- [ ] Open **Manage Summary** and filter the variance lines.
- [ ] Choose between **Accept**, **Recount** and **Investigate** for a line, and justify the choice.
- [ ] Use **Recent Audits** to tell a one-off difference from a recurring one.
- [ ] Assign a recount and act on its result in the **Resolution Summary**.
- [ ] Write a useful closure note.

**Adjustment and completion**

- [ ] Explain how the stock correction is settled for each stock source: Stockount stock, a connected application, or an Excel sheet.
- [ ] Download the **Adjustment Report** for an Excel-sourced audit.
- [ ] Complete an audit, and read what still blocks completion when it is refused.
- [ ] Explain what happens when an audit reaches its auto-completion window.

---

## Audit Contributor

- [ ] View an audit's summary and variance lines.
- [ ] Work on the resolution step: accept, recount or investigate lines and add closure notes.
- [ ] Explain why a contributor cannot complete an audit, and who can.

---

## Administrator

- [ ] Give users Audit and Audit Plan access in **Role Management**.
- [ ] Add or remove owners and contributors on an audit plan.
- [ ] Review and approve a stock adjustment from **Adjust Stocks**.
- [ ] Before approving a correction to a connected application, read the confirmation and check that the company, site and application are the right ones.
- [ ] Explain why adjustment lines cannot be edited.
